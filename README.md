# Crop Guardian: ESP32 Greenhouse Automation Robot

An ESP32-based robot that monitors greenhouse conditions and reacts automatically.

## Features

- Monitors soil moisture, temperature, humidity and light
- Automatic mist spray
- Fan control
- LCD display of live readings

## Hardware

ESP32, DHT11/DHT22, soil moisture sensor, LDR, relay modules, fan, mist sprayer, LCD
